# BusyCal MCP Bundle

BusyCal for Claude is distributed as a signed `.mcpb` bundle through GitHub Releases.

## Install

1. Open the latest release from this repository.
2. Download the BusyCal MCP bundle asset from that release.
3. Open the bundle in Claude Desktop.

## What It Does

- list BusyCal accounts and calendars
- search events, tasks, journals, graphics, and stickies
- query free/busy availability and find the next available slot
- create, update, move, complete, and delete BusyCal events and tasks

## Platform

- macOS only
- Claude Desktop `>= 0.11.0`
- requires BusyCal on the same Mac

## Privacy

BusyCal MCP talks to BusyCal locally on your Mac. It does not relay your calendar data through an external BusyMac service.

## Source Availability

This repository is the public distribution endpoint for the compiled BusyCal MCP bundle and release notes. The BusyCal source repository is private.
